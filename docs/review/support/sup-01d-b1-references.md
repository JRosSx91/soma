## 3. Afirmaciones deliberadamente **no** incluidas

- Que una técnica previene recaídas o trata abstinencia.
- Que el etiquetado emocional es un tratamiento validado para trastornos.
- Protocolos para crisis, ideación o intoxicación.
- Cambios de medicación o deprescripción.
- Teléfonos o servicios locales inventados.
- Resultados garantizados («en X minutos te calmarás»).
